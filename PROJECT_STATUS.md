4. The user is not a programmer: no technical questions, no programmer-level diagnosis. Give click-by-click instructions for anything they must do.

## Known limitations and technical debt
- X29: after a state is loaded the achievement counts (five different fruits, chains in the round, the clean-round streak) start again from zero, so FRUIT BASKET needs five fruits after the load; the progress numbers show only the game that is running (they are not saved between runs). Loading a state that belongs to a game with another number of lives or to player 2 does not allow achievements until a new game starts.
- X28: rounds 5, 9, 13 and 17 are reached in the real-ROM tests by setting the game's level counter (the test cannot play that far), then the round is really cleared by the game; the achievement for round N needs the LEVEL event of round N, so a game that jumped (trainers, removed from the plan) would not unlock the rounds it skipped.
- X27: the repeated-chain achievements are proven on the real ROM by combining the real ghost events of four separate runs (one chain each) into one round, because eaten ghosts need about 800 frames to leave the house again and the test does not play, so a second chain in the same scripted run is unreliable (same method as FRUIT BASKET in X26). One chain, the 1600-point place and the round change are real-ROM facts.
- X26: the five-fruits achievement is proven on the real ROM only by combining the real fruit events of five separate runs (one per round) into one game, because the test cannot jump several rounds in one machine run with RAM pokes; the achievement logic itself is also unit tested. The achievements list now has 11 entries and scrolls; descriptions use only the capitals the game font has.
- X25: only two sample achievements exist so far (X26 to X29 add the real set); the list page shows all of them but has no hidden or progress entries yet; there is no button to lock an achievement again (delete its line in achievements.cfg). The pop-up is drawn over the top of the maze for 3 seconds and waits while the READY screen, a pause or a menu is showing. Only the player-1, 3-lives rule is applied: the bonus-life and difficulty settings do not matter yet.
- X24: the time of a level is measured in machine frames from the start of the level (the READY screen of level 1 is included) to the last dot, so pauses, menus and loads do not count; a game in which a state was loaded or rewound never changes a record. Times are shown in whole seconds (the game font has no full stop). Records have no reset button yet (delete records.cfg to start over). Scores at the end of a level are the score of the player who cleared it.
