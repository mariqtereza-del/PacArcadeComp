What the trace covers: reset, boot_init fill loops, EI and HALT at 2349/234A (instruction ~6230), the interrupt delivered by the board rule (halted + enable + IFF1) through the I=3F table to 3000, then the self-test ROM checksum loop. 300,000 instructions reach 133 distinct PCs.
Negative control: changing one character of a log line at line 5000 makes cmp report 'line 5001', so a difference would be shown with its instruction number.
Setup differences recorded: both sides start with AF=SP=FFFF (real Z80 reset; the Python wrapper alone starts at AF=0002, SP=0, which the oracle overrides). The interrupt is delivered as soon as the CPU is halted rather than after 50,688 cycles (neither side counts cycles here).
Not covered: cycle counts, I/O reads of inputs other than the stub values, frame-timed interrupts (S17/S18).
