N47b evidence: the service-switch test screen, native: ROM 3174-32F8 and its text helper 3AF4 (instruction list generated by tools/gen_attract.py into src/game/attract_prog.h, runner src/game/attract.h, hooks in src/rules/rules.h). 15 entry addresses (about 200 ROM instruction addresses).
FINDING (like N47a): this is not only a test-mode screen. After the self test, every power-on ends with jp 3174. The code sets the I/O ports, enables interrupts, reads the three input ports and the DIP switches, writes the 'test screen' text through 2C5E, and only if the service switch is NOT held it falls through to 3246: it clears the ports, fills the screen from a table with the pop/push loop (3258-327A), runs the delay routine 32ED eight times (each call counts down 10,240 times, about 266,000 cycles = 5 frames), waits for the switch bit, tests the coin bits and jumps to 234B (the start of the game). The later part (32A7-32EA: a test that steps through the input bits, then the 3AF4 text routine) is reached only when that code is not left earlier through 3295 / 32A4 (a coin bit or the switch bit is set); the coverage runs reach it only rarely (see the scope note).
DECISION (recorded, as in N47 and N47a): the native version REPLICATES the ROM frame for frame (same cycles, same RAM writes, the frame ends cut the loops exactly as the ROM is cut). Interrupts stay enabled in the loop 3188 to 3243 and are disabled from 324A on, as in the ROM.
Scope notes (honest): (1) Only the readable-rules mode uses the native code; original-rules mode still runs the ROM. (2) In the coverage runs 3AF4 is entered once and 31FC never (the branch for a DIP value that the test machine never has); those are proved by 100,000 random whole calls each, the cut test and the wrong-version test, not by a real run. (3) New instruction forms: PUSH DE, OR L, DEC E, RLC E, LD (HL),C, LD (HL),D, ADD A,L. (4) The very long entries (32ED and the eight-delay loops) are tested with 1/200 of the random cases; real states are compared in full.
(5) Test-harness fix found and recorded: a loop that jumps back to its own first address (3AFA) ended the ROM run at an address the native run passes at once when the frame end cut it there; the isolated test now goes on until the native machine has used as many cycles as the ROM one (3 of 2000 random cases were wrongly reported before).
