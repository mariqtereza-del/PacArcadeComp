T01f evidence: mode timers (scatter/chase timer, frightened timer, turn-round flags, level settings) as readable code (src/logic/mode_timers.h) versus the ROM (2026-10-15)

== What was written ==
src/logic/mode_timers.h: the scatter/chase timer (ROM 0E36: the frame counter 4DC2 against the level's seven phase limits at 4D86, the phase number 4DC1, frozen while ghosts are blue, and the four turn-round flags 4DB1-4DB4 set at each phase change), the frightened timer (ROM 1376: the counter 4DCB, and the end of the effect: Pac-Man colour 4C0B, the blue flags of ghosts that are not dead, 4DA6, siren 4DC8, ghost chain 4DD0, sound bits 4EAC) and the level start (ROM 070E, which copies the level's speed patterns for Pac-Man and the four ghosts, the seven phase limits, the ghost house dot limits, the two Cruise Elroy limits, the frightened time and the inactivity time; the ROM tables at 0796, 0843-0873 and 330F are written as readable tables: 7 speed rows of 7 speed patterns and 7 phase limits, 21 level rows, ...). The power pill start itself (1A70) is the T01c code.

== How it was proved ==
Compared after every call: ALL work RAM (4C00-4FEF) except the bytes under the stack pointer; for 0E36 and 1376 also the video RAM and the colour RAM. For 070E only the work RAM (the level start also draws the level's fruits in video RAM, ROM 2BEA, which is not copied).
Part A (live): a scripted player for 3,000,000 frames; at every entry of 0E36, 1376 and 070E the readable version gets a copy of the memory; at the return both must be identical.
Part B1: 0E36 alone: every phase number 0-255 x frightened or not x the counter just before / at / after the limit, and EVERY counter value 0-65535 for each phase 0-7: 534,528 calls.
Part B2: 1376 alone: every combination of frightened flag (0,1,2) x the four blue flags x the four dead flags x ten counter values (0, 1, 2, 3, FFFF, ...): 30,720 calls.
Part B3: 070E alone: every level row 0-20, also through the demo pointer (level number 0, the level number then comes from the byte at the ROM address in 4E0A), on random memory: 1,640 calls.
Part B4: 1,000,000 random runs of each of the three routines on completely random memory.

== Honest limits ==
1. The readable code is not used by the game yet; the full 85-minute regression was not rerun (no game code changed).
2. In live play the scripted player only reached phase 3 and 2 different level rows (levels 1 and the demo); phases 4-7 and the other 19 level rows are proved by the isolated runs (all 256 phase numbers, all 65,536 counter values, all 21 level rows). The phase number is doubled in one byte like the ROM does (only phases 0-7 occur in the game).
3. The level start is compared on work RAM only (the fruit drawing, ROM 2BEA, is not copied). Level numbers above the table (more than 21 rows) are not modelled (the ROM would then read beyond its table); the live run saw none.
4. NOT part of T01f: the ghost house release rules and the release at 1066, which the earlier steps do not cover either; the game state machine around these routines.
5. With T01f all six pieces of Track B (T01a-T01f) are written and proved; T01 itself stays PARTIAL because the game does not use the readable code yet.

== Added during S37 (2026-10-15): table layout and re-run ==

The values are the same. Re-run after the change, full size: tests/test_logic_timers.sh 3000000 1000000 -> PASS, 5,464,289 live calls and 3,566,888 isolated calls compared, 0 differences (the same call counts as above).
