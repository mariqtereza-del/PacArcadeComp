== FIX after the user's report (2026-10-13): triggers and every other button bindable ==
Cause: SDL reports L2/R2 (LT/RT) as axes, so the binding screen never saw them. Now an axis pushed past 50% counts as a button press (pseudo-buttons lefttrigger/righttrigger, hysteresis 16384 down / 8192 up). Also bindable: A B X Y, BACK/SELECT/Share, START/Options, L3, R3, LB/L1, RB/R1, Share/Mic (Xbox Share, DualSense Mic), PS button, Touchpad, paddles 1-4. D-pad stays fixed (always moves Pac-Man).
Tests: test_bindings 167 checks (all 17 non-d-pad buttons + 2 triggers bindable, saved to and loaded from controls.cfg, hysteresis), test_menu 126, test_padbuttons driven runs with an SDL virtual pad: L2 as Coin -> credits 1; R2 save; Share/Mic rewind; paddle load; touchpad pause/resume (injected as button 20). run_all passes, scripted hashes unchanged (2400 ticks 60c4b12eb084ed7e, 3000 ticks d7d39438e9e8d70c).
Not tested with a physical pad: the real trigger travel of a DualShock 4 (the virtual pad sends the same SDL axis events).
