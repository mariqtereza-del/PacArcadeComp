How the mechanism works: the native routine runs only whole loop rounds that end before the 50,688-cycle limit, leaves the machine exactly where the ROM would be (pc at the loop head 0008, registers, the RST's return address on the stack, flags, R, WZ) and the ROM runs the last instructions up to the limit itself, so the interrupt arrives at the same instruction as in the original; after the interrupt the hook at the loop head takes the routine over again.
