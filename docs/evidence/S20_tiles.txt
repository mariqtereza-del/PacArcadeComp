C++: src/video/tilemap.cpp (render_tilemap). Test: tests/test_tilemap.cpp (build line in its header). Reference: the prototype's render.py render(mem, gfx, sprites=False) on the exact-frame, mirror-correct board of tools/analysis/oracle_dump.py (the S18 oracle); the plain harness is not used because its RAM differs from the real board after frame 296 (see S18). Reference images are made with:
  python3 - <<'EOF'      (run from the project folder)
  import sys; sys.path.insert(0,'tools/analysis')
  from oracle_dump import MirrorBoard, run_frame_exact
  from render import render
  from harness import load_roms
  prog, gfx = load_roms(); b = MirrorBoard()
  for f in range(1, 1501):
      run_frame_exact(b)
      if f in (700, 1500):
          open('build/s20/py_%d.rgb' % f, 'wb').write(render(b.mem, gfx, sprites=False).convert('RGB').tobytes())
  EOF
