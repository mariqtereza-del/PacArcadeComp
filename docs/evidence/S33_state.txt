S33 Pause, save state, rewind, high score - evidence (2026-10-12)

1. THE VERIFY COMMAND (tests/test_state.sh, 38 checks, PASS, full output in S33_test_state.txt):
   A. A real game (coin 400, start 420, random joystick, same inputs every run). State saved at frame 1800 (main state 3, score 460, 3,300 bytes). 600 frames run and hashed
      (memory, sound registers, latches, CPU PC/SP and the 600 x 1,584 sound samples of every frame); state loaded; the same 600 inputs run again: all 600 frame hashes IDENTICAL,
      and the complete state after the repeat equals the state of an uninterrupted run byte for byte (except the sound-chip struct's padding bytes, which are not state).
   B. The saved bytes loaded into a BRAND NEW machine and sound chip play the same 600 frames identically (nothing is missing from the state). Also at frames 100, 350, 430, 900, 1300, 2000.
   C. State file written/read back identical; damaged, cut-short and other-version states are refused and change nothing; a missing file is reported; the state holds no waveform-ROM
      bytes and no program-ROM runs (252 windows of 32 ROM bytes scanned) - state files can be shared without sharing the ROM.
   D. Rewind: one state per frame; rewinding 120 frames and replaying the same inputs gives the same 120 frames; the ring keeps only the newest N states.
   E. The high-score digits our code draws equal the digits the ROM draws itself, at all 83 changes of a real game's high score (0 tile differences); "00" / "05" rules checked.
   F. High score keeper: stored value put in RAM (4E88-4E8A) and on screen once, at the first attract screen (not during the power-on RAM test, when the state byte counts through
      garbage); a normal game that beats it is saved at game over; a game in which a state was loaded or rewound: only the score reached BEFORE the first load/rewind is saved (after the user's report 2026-10-12), what is scored after does not count; a lower score never replaces the file; leaving mid-game
      saves the score so far only if unassisted; the next game counts again after an assisted one; damaged file ignored.
