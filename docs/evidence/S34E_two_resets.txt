S34E evidence: two RESET TO DEFAULTS buttons, no Purist item, achievements follow the game settings (2026-10-21)

What was built (user request after testing S34D)
  1. No Purist item: the two PURIST MODE rows are gone from the main page. Menu words "PURIST", "LOCKED BY PURIST" are gone (the --purist command-line test flag stays; its menu marks now read TEST / TEST MODE / LOCKED (TEST FLAG)). An old "purist on" line in settings.cfg is still reported and ignored.
  2. DISPLAY page, last item RESET TO DEFAULTS (Enter asks, Enter again resets): overlay, scanlines, scaling, smooth pacing, window frame, key panel, run summary, CRT mask, glow, curve, surround. At once, no restart, the machine is not touched. (The page now has 15 rows; the rows are one pixel closer so the box fits the 288-line picture.)
  3. GAME OPTIONS page, RESET TO DEFAULTS above BACK (Enter asks "ENTER AGAIN. RESTARTS", Enter again resets): lives, bonus life, difficulty, ghost names, RULES (ORIGINAL) and the test cheat; then the game restarts (restart_machine "game settings reset") so they take effect. Display, vibration/pad/hints/light bar (CONTROLS page), key and pad bindings, high score, records, achievements and save slots are not changed. rules.cfg cannot be undone by the button (the log says so).
  4. Achievements: they can unlock only while every game setting is at its standard value, judged on what the running machine really uses: the DIP switch byte the machine sees (lives, bonus, difficulty, names) and RULES (READABLE or a rules file = not standard). A game started or played with a non-default setting never counts afterwards (the engine's "eligible" flag drops and only the next game start restores it). The log says once when the settings leave the standard and when they are back; the menu footer says NO ACHIEVEMENTS: OPTIONS; the rule text on the ACHIEVEMENTS page reads PLAYER 1, STANDARD GAME OPTIONS, NO REWIND. Records, the saved high score and statistics are not affected by this rule (they were never tied to lives/bonus/difficulty).
  5. Display settings and save states: display settings never reach the achievement engine (proved below). A loaded save state does not stop achievements (this was already the rule since X29 and is kept); it still marks the game for records and statistics. Rewind and the other assists still stop achievements.
  Honest note: because loading a state does not stop achievements, a player can save before a risky moment and reload until it works. This is what the user asked for.
