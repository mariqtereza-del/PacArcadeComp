Notes
- The helpers push return addresses on the stack inside the ROM (the RST 10h inside 0018 and 0020, PUSH HL in 0028); those stack bytes are part of the hashed memory, so the adapters write them (found by the random-state test; the first version without them passed the real-state comparison by luck).
- WZ (MEMPTR) is set exactly too, because two ROM places use BIT n,(HL), whose flags depend on it.
- 0008 is also the loop head of the fill (DJNZ 0008), 0010 is called inside 0018 and 0020, 0042 inside 0028: the native versions do not call each other, so the call counts of those three differ from the ROM's entry counts by design; 0018, 0020, 0028 and 0030 are compared one to one (equal).
- The routine map (docs/notes/rom_routines.md) shows no callers of 0008 because RST 08 is not counted as a call there; the run shows it is used (the native fill ran 129,039 times in the lockstep run).
