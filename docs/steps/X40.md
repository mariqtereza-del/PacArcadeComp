# STEP X40: CRT effect: shadow mask
Status: **VERIFIED**   Lane: EXTRAS   Depends on: S34V

OBJECTIVE: An optional phosphor shadow mask (fine red/green/blue stripes) over the picture at the window's real size, strength adjustable. It never touches the emulated picture buffer.

WHY: First of the CRT looks, simplest to measure.

STARTING STATE: The steps it depends on are VERIFIED. Rules shared by every X step are at the top of tools/plan_data_x.py (assist rule, Purist off, new code in new files).

READ FIRST: docs/notes/ram_map.md, PROJECT_STATUS.md and the files named in MAY TOUCH

MAY TOUCH (only these): src/app/crt.h (new), src/app/menu.*, src/app/main.cpp (wiring)

IMPLEMENT:
- Applied in the output stage after scaling (same place as the S31 scanlines).
- Settings: Mask Off / Light / Strong; Purist off.

DO NOT:
- No change to the emulation: the extra only reads memory, lives outside the machine, or is an assist (the game then stops counting for records).
- The Reset to defaults button puts it back to its default unless this step says otherwise; replay hashes must stay identical (tests/test_purist.sh, tests/test_replay.sh).

VERIFY:
- Unit test: mask pattern and brightness average
- Real-window screenshots at three sizes
- Speed test: no frame time problem at 1920x1080 and 2560x1440 (measured)
- Scripted replay and Purist hashes unchanged

SUCCESS CRITERIA: All checks pass; replay and Purist hashes identical.

IF FAILURE: Stop. Re-run only this step's VERIFY command. Undo the last edit and retry. Compare against the Python prototype (tools/analysis) as the reference. Write what you found in docs/evidence/X40_failure.md. Do not start the next step.

DOCUMENT: In PROJECT_STATUS.md set this step's row (status, date, evidence path), add a line under Changes and Known limitations, and set Next step. Set the status in tools/plan_data.py and run python3 tools/make_plan.py.

EVIDENCE TO RECORD: docs/evidence/X40_crt1.txt

CHECKPOINT: Run sh tests/run_all.sh (all earlier tests must still pass), then sh tools/checkpoint.sh X40 and send the zip to the user.

USER ACTIONS (tell the user in plain click-by-click words; see the Standard test routine in the plan page):
- Display > CRT mask: Light and Strong; the picture should look like a monitor's glass, not dirty.
