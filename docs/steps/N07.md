# STEP N07: Cycle meter: the exact time a ROM routine takes
Status: **NOT STARTED**   Lane: NATIVE   Depends on: N06

OBJECTIVE: A test tool that measures, for any ROM routine, the exact cycles and instruction count from entry to return in every call of the coverage runs, and helps to find the formula (constant, per loop turn, per byte).

WHY: Every replaced routine must take the same time as the original; this tool finds and checks the numbers.

STARTING STATE: The earlier N steps are VERIFIED.

READ FIRST: docs/notes/rom_routines.md (from step N01), the step's evidence files

MAY TOUCH (only these): tests/cycle_meter.h, tests/test_cycle_meter.*

DO NOT:

- The Z80 stays until the removal step: ROM routines that are not replaced yet keep running. Hooks are off unless the readable rules are switched on; Purist mode always runs the original ROM routines (until the removal step).
- Never put ROM bytes into the source: tables come from the player's ROM at run time (src/data/), tools/export_github.sh must stay clean.
- If a step would take longer than about 20 minutes, stop and split it (a, b) in the plan; do not squeeze it in.

- The meter reproduces 111 cycles and 13 instructions for the random-number routine, and a known loop (the fill routine) as a formula
