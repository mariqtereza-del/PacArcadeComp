# STEP X54: Two players online: turn-based game
Status: **NOT STARTED**   Lane: ONLINE   Depends on: X53

OBJECTIVE: NOTE (2026-10-14): replays were removed from the plan; this step now uses only the machine hash check described here. The ROM's own 2-player game over the internet: both programs run the same machine; during a player's turn the active player's inputs travel to the other, who watches with a short delay buffer; at the change of turn control passes. No rollback is needed because only the active player's inputs matter.

WHY: The honest, simple version of 'netplay for a deterministic emulator'.

STARTING STATE: The steps it depends on are VERIFIED. Rules shared by every X step are at the top of tools/plan_data_x.py (assist rule, Purist off, new code in new files).

READ FIRST: docs/notes/ram_map.md, PROJECT_STATUS.md and the files named in MAY TOUCH

MAY TOUCH (only these): src/app/net.h, src/app/main.cpp

IMPLEMENT:
- Input stream with frame numbers; the watcher runs a few frames behind; a hash of the machine every second detects any difference.
- A dropped connection pauses and offers to continue alone.

DO NOT:
- No change to the emulation: the extra only reads memory, lives outside the machine, or is an assist (the game then stops counting for records).
- Purist mode switches it off unless this step says otherwise; replay hashes must stay identical (tests/test_purist.sh, tests/test_replay.sh).

VERIFY:
- Two local instances play a scripted 2-player game; hashes equal every frame on both
- Scripted replay and Purist hashes unchanged

SUCCESS CRITERIA: All checks pass; replay and Purist hashes identical.

IF FAILURE: Stop. Re-run only this step's VERIFY command. Undo the last edit and retry. Compare against the Python prototype (tools/analysis) as the reference. Write what you found in docs/evidence/X54_failure.md. Do not start the next step.

DOCUMENT: In PROJECT_STATUS.md set this step's row (status, date, evidence path), add a line under Changes and Known limitations, and set Next step. Set the status in tools/plan_data.py and run python3 tools/make_plan.py.

EVIDENCE TO RECORD: docs/evidence/X54_net2.txt

CHECKPOINT: Run sh tests/run_all.sh (all earlier tests must still pass), then sh tools/checkpoint.sh X54 and send the zip to the user.
