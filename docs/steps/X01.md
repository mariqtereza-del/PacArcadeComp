# STEP X01: Game event reader
Status: **VERIFIED**   Lane: EXTRAS   Depends on: S34V

OBJECTIVE: One small module (src/app/events.h) turns the machine's memory into typed game events every frame: game start, game over, death, dot, energizer, ghost eaten (with its place in the chain 1 to 4), fruit appeared, fruit eaten (which fruit), round cleared, extra life, level number, player 1 or 2, lives.

WHY: Achievements, statistics, personal bests, challenges and the lightbar all need the same facts; doing it once avoids five slightly different readers. The vibration engine (S34V, verified) is left alone.

STARTING STATE: The steps it depends on are VERIFIED. Rules shared by every X step are at the top of tools/plan_data_x.py (assist rule, Purist off, new code in new files).

READ FIRST: docs/notes/ram_map.md, PROJECT_STATUS.md and the files named in MAY TOUCH

MAY TOUCH (only these): src/app/events.h (new), tests/test_events.*, docs/notes/ram_map.md

IMPLEMENT:
- Read only RAM (docs/notes/ram_map.md: score 4E80/4E84, lives 4E14, level 4E13, dots 4E0E, death animation 4DA5, power-up 4DA6, edible flags 4DA7-4DAA, fruit 4DD2, player 4E09 ...). Where the map lacks an address (fruit kind, fruit eaten flag, game-over, round clear) find it with a short experiment on the Python prototype and record it in docs/notes/ram_map.md.
- Events carry the machine frame number and the player; the chain place comes from the score step 200/400/800/1600.
- A text log option (--events FILE) lists every event, for tests.

DO NOT:
- No change to the emulation: the extra only reads memory, lives outside the machine, or is an assist (the game then stops counting for records).
- Purist mode switches it off unless this step says otherwise; replay hashes must stay identical (tests/test_purist.sh, tests/test_replay.sh).

VERIFY:
- Unit test on made-up frames for every event type
- Real replay (S27, 7,273 frames): event counts equal the game's own counters (dots = 4E0E steps, deaths = 4DA5 episodes, coins, energizers)
- Scripted replay and Purist hashes unchanged

SUCCESS CRITERIA: All checks pass; replay and Purist hashes identical.
