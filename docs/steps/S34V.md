# STEP S34V: Pad vibration (Xbox, DualShock 4, DualSense)
Status: **VERIFIED**   Lane: POLISH   Depends on: S34A

OBJECTIVE: The pad shakes at the right moments of the game, with every pad type: Xbox / XInput, DualShock 4 and DualSense (also a DualShock behind DS4Windows). A Vibration option (Off, Light, Full) is in the menu; Purist mode has no vibration.

WHY: The game is felt as well as seen and heard: a purr for dots, a thump for a power pellet, a harder thump for each ghost in a chain, a long crumbling rumble at death, and a heartbeat when a ghost is close.

STARTING STATE: S34A exists. S34B (pad buttons) is waiting for the user's test but this step does not depend on it: it adds its own file and a few lines in the menu and main.cpp. The program never used the pad's motors before.

READ FIRST: src/app/menu.*, docs/notes/ram_map.md

MAY TOUCH (only these): src/app/haptics.h (new), src/app/menu.*, src/app/main.cpp (wiring), tests

IMPLEMENT:
- A small engine (src/app/haptics.h) reads a few RAM values after each frame (score, lives, level, credits, death animation, power-up, ghost and Pac-Man positions) and never writes to the machine.
- Effects: coin tick; a tiny tick for each dot (Full only); energizer thump; ghost thump that grows along the chain 200, 400, 800, 1600; fruit double tap; extra-life triple tap; long fading death rumble; level-done double pulse; soft tick when the ghosts stop being blue; a heartbeat (lub-dub) that gets stronger as a ghost that can hurt you comes within about 28 picture pixels (Full only).
- Pad types from SDL: Xbox 360 / Xbox One (also what DS4Windows shows), PlayStation 4, PlayStation 5, other. The pattern is the same; the strength of the two motors differs per type (starting values, to be tuned by the user's test) and the trigger motors are used on Xbox One pads only.
- Menu Controls > Vibration: Off, Light (softer, no dots, no heartbeat), Full; kept in settings.cfg; changing it gives a short sample. Purist mode: no vibration. Nothing shakes while paused, in a menu, rewinding, or after a load.
- Nothing is judged during the board's power-on self-test (first 320 frames) because the ROM fills memory with test patterns then.

DO NOT:
- No change to the emulation: the engine only reads memory.
- No vibration without a pad that reports rumble motors; no crash without a pad.

VERIFY:
- Unit test of the engine on made-up frames (every effect, the ghost chain, the heartbeat distances, Light, Off, restart, per-type strengths)
- Driven run: the S27 replay (7,273 frames, with a recorded real game) plays on a pretend pad of each type (SDL virtual joystick, which records every motor command it gets); counts of coin, dot, energizer, death, fright-end events checked against the game's own counters
- Light, Off and Purist runs send nothing to the pad (or less), as specified
- Scripted replay hashes unchanged

SUCCESS CRITERIA: All checks pass; the pretend pads of all four types receive the commands; hashes identical.

IF FAILURE: Stop. Re-run only this step's VERIFY command. Undo the last edit and retry. Compare against the Python prototype (tools/analysis) as the reference. Write what you found in docs/evidence/S34V_failure.md. Do not start the next step.

DOCUMENT: In PROJECT_STATUS.md set this step's row (status, date, evidence path), add a line under Changes and Known limitations, and set Next step. Set the status in tools/plan_data.py and run python3 tools/make_plan.py.

EVIDENCE TO RECORD: docs/evidence/S34V_vibration.txt

CHECKPOINT: Run sh tests/run_all.sh (all earlier tests must still pass), then sh tools/checkpoint.sh S34V and send the zip to the user.

USER ACTIONS (tell the user in plain click-by-click words; see the Standard test routine in the plan page):
- Plug in your DualShock 4 (cable or Bluetooth), start the game, play: you should feel a light purr while eating dots, a thump on a power pellet, a harder thump for each ghost you eat, a long rumble when you die, and a heartbeat when a ghost is right behind you.
- Repeat with the DualSense and with the DS4Windows (Xbox-type) pad. Tell me which feel too weak or too strong.
- Esc > Controls > Vibration: try Light and Off, and Purist mode (no vibration).
