# STEP T02i: T02i: RULES setting and the rules file
Status: **VERIFIED**   Lane: MODDING   Depends on: T02h

OBJECTIVE: Esc > GAME OPTIONS > RULES: ORIGINAL (the standard: the ROM's own routines) or READABLE (the proved readable rules). A text file rules.cfg (next to the program or in the settings folder) can change the numbers in the readable rules without programming: speeds per level, scatter/chase times, frightened times, Cruise Elroy limits, points for dots, energizers, ghosts and fruit, the extra-life score, ghost house limits. With a rules file the game uses READABLE, shows MODDED in the window title, and modded games do not count for the saved high score, records and achievements (the assisted-game rule). Purist mode always uses ORIGINAL and ignores the file. Wrong lines are reported in the log and ignored.

WHY: Anyone can change the game with Notepad; programmers can change the C++ in src/logic.

STARTING STATE: The earlier T02 steps are VERIFIED.

READ FIRST: docs/notes/settings_table.md, src/app/menu.*, src/app/assist.h

MAY TOUCH (only these): src/app/menu.*, src/app/main.cpp, src/app/assist.h, src/rules/, docs/notes/settings_table.md, tests/test_rules_*, tests/test_menu.sh, tests/test_integration.*

IMPLEMENT:
- Settings key rules (original, readable); rules file reader with one line per value, a comment line explaining each; a command to write the standard file (all original values) so modders start from it.
- Tests: no file + ORIGINAL: hashes identical to before; READABLE without a file: identical; a test mod (for example slower ghosts) measurably changes the game (ghost positions differ, the replay shows it); bad lines are reported; Purist ignores the file; a modded game does not save a high score.

DO NOT:
- The game must stay identical with the original rules: with RULES ORIGINAL (the standard) nothing may change at all, and with RULES READABLE every frame hash must equal the ROM run.
- Purist mode always runs the original ROM routines (never the readable rules).
- Never put ROM bytes into the source (tools/export_github.sh must stay clean).
