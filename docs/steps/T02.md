# STEP T02: The game runs the readable rules (Track C)
Status: **PARTIAL**   Lane: MODDING   Depends on: T01f, S37

OBJECTIVE: Let the game call the proven readable rules (src/logic) instead of the original ROM routines, one piece at a time, each time proving the game stays identical; then make the rules easy to change (a rules file, a menu setting, example mods, a modding guide) and publish the result.

WHY: User request (2026-10-15): full modding capabilities for anyone. Until now the readable rules were proved but not used, so editing them changed nothing.

STARTING STATE: T01a to T01f VERIFIED, S37 VERIFIED (published on GitHub).

READ FIRST: src/logic/README.md, MODDING.md

MAY TOUCH (only these): see the sub-steps

IMPLEMENT:
- Sub-steps: T02a hook mechanism and random numbers in use; T02b scoring; T02c dots and fruit; T02d ghost targeting; T02e movement; T02f mode timers and level settings (milestone: full regression); T02g ghost house release as readable code (the main rule T01 did not cover); T02h ghost house release in use; T02i the RULES menu setting and the rules file; T02j modding guide and example mods; T02k release 1.1.0 and GitHub update.
- Method: when the readable rules are on, the machine stops before the first instruction of a ROM routine, the adapter in src/rules/ reads the same registers and memory, calls the readable code, writes the results and returns exactly like the ROM routine's RET (or hands a drawing part on to the original ROM code). Proof: the frame hash of the whole machine (work RAM, video RAM, sprite registers) equals the ROM run on every frame of the replay test and of a 3,000,000-frame scripted run; registers that the readable code does not set are filled with garbage in a second run to prove the game never reads them.

DO NOT:
- Not covered even at the end (honest limit, written in MODDING.md): the game's flow (attract mode, intermissions, death and level-end sequences), the drawing of the maze and text, and the sound sequences stay original ROM code. They can be added later the same way.

VERIFY:

SUCCESS CRITERIA: Zero differences in every sub-step.
