# N05: reasons and decisions for the ROM instructions that no coverage player executes. Used by tests/rom_unreached.py.
# Format: FIRST-LAST | class | reason | decision        (addresses in hexadecimal; the ranges cover instruction start addresses)
# Decision words: PORT = the native game contains it (proved with the isolated random-state test of its routine, as in T02b to T02h, when no play situation reaches it);
#                 LEAVE OUT = the native game does not contain it (reason given); N47 = decided in step N47 (power-on self test).
0038-003F | dead code | RST 38h vector: kicks the watchdog and loops; nothing in the program calls RST 38h and the board raises no such interrupt (the interrupt vector is a ROM table entry) | LEAVE OUT
005A-005A | loop end | end of the slot search of the task queue (RST 28h/30h): reached only when all 16 slots are in use, which the game never does | PORT (one instruction)
1B31-1B35 | needs a rare game state | branch of the ghost-house dot counting (1B08 to 1B35): when the flag at 4DA1 is zero the counter 4E0F is incremented; no run produced that combination of flags | PORT; proved with random states in the step of the ghost-house routine
23E8-23EC | table entry | one slot (23D4) of a state jump table, indexed by the state byte 4E04; no run selected it | PORT (it is a table entry: it runs only if the state counter says so)
2B73-2B77 | data inside code | five inline data bytes after a CALL to 2BCD (parameters of the call), listed as instructions by the disassembler; never executed as code | PORT AS DATA
2C44-2C5D | dead code | BCD conversion routine with no caller and no way in (the instruction before it is a jump) | LEAVE OUT
2D07-2D0B | needs a rare game state | sound update (group B, 2CC1 to 2D0B): the branch taken when the byte at 4EEC is non-zero at this point; no run produced it | PORT; proved with random states in the step of the sound routine
2D58-2D58 | loop end | end of an 8-step bit search when the effect byte has no bit set; reached only for an effect byte of zero | PORT (one instruction)
2DB7-2DB7 | needs a rare game state | sound update (group A): parameter cleared when bit 3 of the channel byte (ix+0B) is set; no run set it | PORT; proved with random states
2E28-2E28 | loop end | end of an 8-step bit search when the effect byte has no bit set; reached only for an effect byte of zero | PORT (one instruction)
2F2B-2F33 | table entry | entries of the jump table at 2F02 (sound parameter handling) that no run selected | PORT (table entries; they run only if the data says so)
2F3C-2F54 | table entry | entries of the jump table at 2F02 (sound parameter handling) that no run selected (11 of them are a bare RET) | PORT (table entries; they run only if the data says so)
3031-303F | power-on self test | RAM test: the path taken when a RAM cell does not hold its pattern (error code to the test screen) | N47
30B5-30BB | power-on self test | RAM test: the path taken when a RAM cell does not hold its pattern | N47
30FB-3151 | power-on self test | drawing of the RAM-test error screen and wait for the service switch | N47
